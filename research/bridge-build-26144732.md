# Привязки экспериментального модуля

Поддерживается только SHA-256 клиента, указанный в `src/bridge_win32_common.hpp`.
Значения в `src/bridge_build.hpp` проверены чтением присланного PE, статических
записей классов и дизассемблированием вызывающих функций. Это статические
свидетельства; ABI, этап кадра и поведение материалов нуждаются в проверке игры.
Исходные DLL не распространяются вместе с проектом.

| Назначение | RVA | Основание |
| --- | --- | --- |
| Source2Client002 vtable | `0x1c65030` | Регистрация интерфейса и RTTI основной таблицы |
| Обработчик этапа кадра | `0xb6e540` | Слот 36; switch этапов и RTTI лямбды FrameStageNotify |
| Очистка материалов | `0x14e9d00` | Вызов из функции регенерации; аргумент weapon + `0x610` |
| Обновление одного оружия | `0x803780` | Вызов после очистки в той же функции; внутренние custom data weapon + `0x1a80` |
| Изменение mesh mask | `0xac4ff0` | Обращение к node + `0x140` + `0x208` и уведомление модели |
| Чтение paint kit | `0x118ecd0` | Слот 3 ItemView, ссылка на атрибут `set item texture prefab` |
| Vtable CEconItemAttribute | `0x1d20360` | RTTI и итератор атрибутов с шагом `0x48` |
| Entity list | `0x271c8b8` | RIP-relative запись указателя и сверка закреплённой таблицы a2x |
| Local pawn | `0x25676d8` | Поле prediction base + `0xf8` и та же сверка |

Обработчик вызывается после оригинального callback при `stage == 6`.
Соответствие этого этапа ожидаемому моменту обновления требует запуска CS2.
Нулевой счётчик Frames не выдаётся за успешное применение.

Ранее встречавшийся слот 33 интерфейса у этого клиента имеет другое назначение.
Используется слот 36 и сравнение адреса до установки. Не изменяются инструкции
функции регенерации: старое смещение патча `+0x52` относится здесь к другому коду.

Entity handle проверяется по индексу и serial, identity имеет шаг `0x70`.
HUD-модель ищется среди ограниченного числа дочерних узлов рук по owner handle
выбранного оружия. Если действующие объекты не найдены, команда остаётся Waiting.
Модель оружия должна совпадать с выбранной Definition ID; подмена Definition ID
ножа или другого предмета не выполняется.

Для покрытия формируются атрибуты 6/7/8 (paint/seed/wear), сохраняя прочие записи.
Вектор ItemView временно ссылается на этот буфер на время нативных вызовов, затем
восстанавливается через SEH finally. Буфер остаётся жив до выхода процесса даже
при ошибке восстановления. Накопление ограничено 256 обновлениями.
Первый readback проверяет лишь то, что нативный клиент прочитал ожидаемый Paint ID;
не проверяются завершение асинхронного рендера и внешний вид.

Источник данных каталога и его `legacy_model`: закреплённый снимок ByMykel/CSGO-API
из `tools/update_catalog.py`. Исходное значение теперь сохраняется в таблице;
выбор старого меша не выводится из номера покрытия.

Тесты запускают DLL только в неподходящем процессе и проверяют отказ до установки
обработчиков. Запуск самого клиента, работа в ММ, стабильность после синхронизации
с сервером и восстановление внешнего вида в среде разработки недоступны.
