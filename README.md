# CS2 Project

Редактор профилей с каталогом скинов для Windows 11 x64 на C++17, Dear ImGui и Direct3D 11.
Светлое меню с розовыми акцентами построено по предоставленным референсам.

**Это редактор локальных профилей, а не работающий скинченджер. Интеграция с CS2
не реализована. Программа не меняет предметы, музыку, камеру или окружение в игре.**
Работа в Premier и матчмейкинге не проверена. Сборка `.exe` и тесты профилей
не подтверждают работу в CS2.

## Что реализовано

- Вкладки **Skins**, **World**, **Settings**, категории оружия, ножей, перчаток и музыки.
- Один предмет на профиль: definition ID, paint kit ID, wear, seed, StatTrak,
  пользовательское имя и выбор T/CT. Список моделей содержит распространённые ID;
  совместимость с текущей версией игры не проверяется.
- Локальные настройки музыкального набора, неба, освещения, экспозиции, FOV,
  положения оружия, третьего лица, погоды, влажности и ветра.
- Сохранение, загрузка, сброс и проверка профилей. Ошибочная загрузка сохраняет
  текущие настройки; ошибочное сохранение не должно уничтожать предыдущий файл.
- Подтверждение потери несохранённых изменений при загрузке, сбросе и закрытии.
- Кнопка применения к игре отключена и явно обозначена как недоступная.
- Каталог **2 126 скинов / 63 модели**, поиск по названию или Paint Kit ID,
  отдельные названия фаз Doppler, изображение выбранного скина, превью при наведении
  на строку и увеличенный просмотр по нажатию на картинку.
- PNG входят в архив: после распаковки интернет для просмотра не нужен.

Превью — статичная картинка предмета из каталога, а не 3D-рендер. Изменение Wear,
Seed, StatTrak и имени не меняет картинку. Для точного воспроизведения рисунка
и износа потребуется отдельный рендерер. 3D-превью, аудиопревью и связь с клиентом отсутствуют.
Некоторые категории и элементы референсов ещё не реализованы. Диапазоны в редакторе
служат проверке ввода, а не спецификацией поддерживаемых игрой значений.

## Сборка на Windows

Нужны Git, Python 3.9+, CMake 3.24+ и Visual Studio 2022 с компонентом **Desktop development with C++**.
В терминале из корня репозитория:

```powershell
python tools/download_previews.py
cmake -S . -B build/windows-msvc -A x64
cmake --build build/windows-msvc --config Release --parallel 2
ctest --test-dir build/windows-msvc -C Release --output-on-failure
.\build\windows-msvc\Release\cs2_profiles.exe
```

Dear ImGui загружается из официального репозитория с фиксированным коммитом
`f5befd2d29e66809cd1110a152e375a7f1981f06` (v1.91.9b). Первый запуск CMake требует
доступа к GitHub. Приложение не требует запуска CS2 и не запрашивает права администратора.

## Просмотр скинов

Распакуйте **весь ZIP**, сохранив папку `previews` рядом с `cs2_profiles.exe`.
В Skins выберите категорию, модель и скин из списка Paint kits. Справа появится
изображение; нажатие на него открывает увеличенный просмотр. Поиск работает по
английскому названию и числу Paint Kit ID. При наведении на строку показывается
небольшое превью. Смена скина обновляет локальный профиль и ограничивает Wear
диапазоном выбранного скина из каталога.

При загрузке сохранённого профиля превью определяется парой Definition ID / Paint Kit ID.
Неизвестная комбинация не показывает чужую картинку. В случае отсутствующего или
повреждённого файла отображается ошибка и кнопка Retry image.

Каталог зафиксирован на снимке ByMykel/CSGO-API; источник и лицензии перечислены в
[THIRD_PARTY_NOTICES.md](THIRD_PARTY_NOTICES.md). `tools/update_catalog.py` обновляет
генерируемые таблицы из указанного в нём коммита. `tools/download_previews.py`
скачивает изображения с HTTPS CDN Steam, проверяет структуру и CRC PNG и сохраняет
их в игнорируемую папку `assets/previews`. Этот шаг выполняется при подготовке сборки,
а не при запуске приложения. Все изображения должны успешно загрузиться до упаковки.

## Профили

Вкладка **Settings** позволяет задать имя профиля и выполнить Save / Load / Reset.
При запуске загружается `default`, если он существует. Другие профили загружаются
вручную по имени. Нижняя кнопка Save сохраняет профиль с указанным в Settings именем.

Файлы хранятся в:

```text
%LOCALAPPDATA%\CS2Project\profiles\profile-<name>.cs2profile
```

Имена профилей: латинские буквы, цифры, дефис и подчёркивание. Файлы содержат
версионированный текст UTF-8; поддерживаются LF и CRLF. Загрузка отвергает
повторяющиеся, неизвестные и пропущенные поля, неподдерживаемую версию, неверные
значения и файлы больше 64 КиБ. Пользовательское имя предмета ограничено 128 байтами
UTF-8. Это ограничение редактора; ограничения имени в CS2 отдельно не проверены.
Для кириллицы интерфейс использует Segoe UI из установленной Windows.

## Тесты на Linux

Для независимых от Windows проверок достаточно C++17-компилятора и CMake:

```sh
cmake -S . -B build/native -DCMAKE_BUILD_TYPE=Debug -DBUILD_DESKTOP=OFF
cmake --build build/native --parallel 2
ctest --test-dir build/native --output-on-failure
```

Четыре группы проверяют точность сохранения и загрузки, некорректные профили,
границы значений, файловые операции и сохранность данных при ошибках. Дополнительный
тест проверяет каталог, поиск, различимость фаз и сопоставление предметов с изображениями.
На Windows также проверяются декодирование всех 2 126 картинок через WIC, прозрачность,
повреждённые файлы, пути с кириллицей и запуск окна с показом трёх разных скинов.
Режим `cs2_profiles.exe --preview-smoke-test` завершает приложение после проверки
и не загружает/сохраняет пользовательские профили.

## Кросс-сборка Windows из Linux

Поддержан toolchain для Zig 0.14.1. Нужны CMake, Ninja и Zig:

```sh
cmake -S . -B build/windows -G Ninja \
  -DCMAKE_TOOLCHAIN_FILE=cmake/zig-windows.cmake \
  -DZIG_EXECUTABLE=/absolute/path/to/zig \
  -DCMAKE_BUILD_TYPE=Release -DBUILD_TESTING=OFF -DBUILD_DESKTOP=ON
cmake --build build/windows --parallel 2
```

Результат: `build/windows/cs2_profiles.exe`. Кросс-сборка проверяет компиляцию
и компоновку; для проверки окна, Direct3D, DPI и пользовательских сценариев
нужен запуск на Windows. Процессы CI из `.github/workflows/build.yml` собирают
Linux-тесты и Windows-приложение; Windows job также выполняет тесты профилей.
Windows job подготавливает все картинки и включает папку `previews` в архив.

## Следующий этап

Для реальной интеграции требуется исследование актуального клиента и доступная
Windows-машина с CS2 для проверки каждого параметра. Ни один эффект в игре пока
не подтверждён. Состояние интеграции намеренно видно в заголовке, информационной
строке, Settings и на кнопках применения.
